# TFL-Proof-Game_Anderson_Blane
This is my game TFL proof and Soundness Proof game!


Play:
Level 1: Match each rule name with its correct form
Level 2: Identify which rule corresponds to each soundness proof


Download and Run Locally!


Step 1: Download
Go to the GitHub repository:
👉 https://github.com/anderblm/TFL-Proof-Game_Anderson_Blane
Click the green Code button
Click Download ZIP
Step 2: Extract Files
Locate the downloaded .zip file
Right-click → Extract All
Open the extracted folder
Step 3: Run the Game
Find the file named:
index.html
Double-click it

👉 The game will open in your web browser
