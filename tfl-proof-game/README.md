# TFL Proof Rules Game

Open this project in Cursor.

## How to open
1. Open Cursor.
2. Click File > Open Folder.
3. Choose this folder.
4. Open `index.html`.

## How to run
Option 1: Double-click `index.html` to open it in your browser.

Option 2: In Cursor, install the Live Server extension, then right-click `index.html` and choose "Open with Live Server".

Important: Do not try to edit the `.zip` file directly. Unzip it first, then open the folder or open `index.html`.
